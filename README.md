# MeatHub: An E-Commerce Marketplace for Local Meat Producers

**Student Name:** Queen Ashley Factor  
**Course:** Web System and Technologies 2  
**Section:** BSIT III - F2

## Project Description

MeatHub is an e-commerce marketplace that connects local meat producers and suppliers with customers. Sellers can manage products, prices, and inventory, while customers can browse products, place orders, and reserve meat for pickup.

The platform earns revenue through commissions on successful transactions and featured product listings.
